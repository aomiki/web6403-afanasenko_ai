# Лабораторная работа №3

**Тема**: основы JavaScript — набор функций по заданию из каркаса [js-tasks](https://github.com/teach-kirshdv/js-tasks).

Проект лежит в папке [`lab3`](lab3), решения — в `lab3/src/core.js`, тесты — в `lab3/src/core.spec.js`.

## Запуск тестов

```bash
cd lab3
npm install
npm test
```

## Функции

| Функция | Что делает |
| --- | --- |
| `isInteger(n)` | Проверяет, целое ли число (через побитовое `n \| 0`) |
| `even()` | Возвращает массив чётных чисел от 2 до 20 |
| `sumTo(n)` | Сумма чисел от 1 до n циклом |
| `recSumTo(n)` | Сумма чисел от 1 до n рекурсией |
| `factorial(n)` | Факториал n |
| `isBinary(n)` | Является ли n степенью двойки |
| `fibonacci(n)` | n-е число Фибоначчи |
| `getOperationFn(initialValue, operatorFn)` | Функция, которая накапливает значение операцией (замыкание) |
| `sequence(start, step)` | Генератор арифметической прогрессии (замыкание) |
| `deepEqual(a, b)` | Глубокое сравнение двух значений |
